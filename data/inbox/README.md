# 거래내역 파일 넣는 곳 (단일 폴더)

증권사 구분 없이 **이 폴더 하나에** 다운로드한 CSV를 전부 넣으면 된다.
`python3 cli.py sync` 가 파일명을 읽어 자동 분류·적재한다. (재실행 시 중복 자동 skip)

## 파일명 규칙

```
계좌명_이름_증권사_계좌번호_연도.csv
```

- 예: `금현물_영한_미래에셋증권_112-0509-1122-3_2025.csv`
- **연도 생략 가능** = 전체 통합본. 예: `종합(성장)_영한_KB증권_265-929-085-01.csv`
- 연도는 `YYYY` 또는 `YYYYMM`.
- 계좌명(맨 앞)에는 언더바가 들어가도 되지만, 이름/증권사/계좌번호에는 넣지 말 것.
  파싱은 오른쪽부터: (연도) - 계좌번호 - 증권사 - 이름 - 나머지=계좌명.
- 같은 계좌(증권사+계좌번호)의 연도별 파일은 여러 개 넣으면 누적된다.

## 인식되는 증권사

미래에셋증권 / 키움증권 / 삼성증권 / KB증권 (`app/ingest/adapters.py`의 BROKERAGE_ALIASES)

## 어댑터 상태

- **미래에셋증권**: ✅ 실제 파일 기준 확정(전용 파서 + 예수금 추출).
- **키움/삼성/KB**: ⚠ 컬럼 매핑 placeholder → 실제 파일 헤더로 맞춰야 파싱됨.
