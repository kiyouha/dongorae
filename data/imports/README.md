# imports — 자동 적재 폴더

증권사 거래내역 파일(csv/xlsx)을 **이 폴더에 넣기만 하면** 서버가 자동으로 감지해 적재합니다.
도커에 접속할 필요 없이 **NAS File Station / SMB 공유**로 넣으면 됩니다.

- NAS 호스트 경로: `/volume2/docker/goraes/dongorae/data/imports/`
- 컨테이너 경로: `/app/data/imports/` (같은 폴더를 바인드 마운트)

## 파일명 규칙

```
소유주_계좌명_증권사_계좌번호[_연도].csv    (또는 .xlsx)
```

예)
```
김영한_종합_미래에셋증권_112-0509-1122-0_2024.xlsx
김영한_CMA_삼성증권_7156714951-05_2025.csv
김숙진_연금저축_미래에셋증권_112-0509-1122-2.xlsx      ← 연도 생략 가능
```

- **소유주**: 첫 토큰(한 단어).
- **계좌명**: 소유주와 증권사 사이. 밑줄이 없어야 안전(공백은 가능).
- **증권사**: `미래에셋증권 / 키움증권 / 삼성증권 / KB증권`(별칭도 인식: 미래에셋·키움·삼성·국민증권 등).
- **계좌번호**: 뒤에서 두 번째 토큰(하이픈 포함 가능).
- **연도**: 선택. `2024`, `202406`, `2024-2025`(범위) 가능. 없어도 적재는 정상 —
  중복은 파일 내용 해시로 걸러지므로 문제 없습니다. 다만 여러 해 파일을 구분·보관하려면 붙이는 것이 좋습니다.

## 동작

- **매 1분** 크론이 이 폴더를 스캔합니다(변경된 파일만; `.manifest.json`에 mtime·size 기록).
- 관리 탭 **[imports 지금 스캔]** 버튼으로 즉시 실행할 수도 있습니다.
- 같은 파일을 다시 넣거나 겹치는 기간을 넣어도 **중복 적재되지 않습니다**(행 단위 내용 해시 dedup).
- 웹 업로드로 올린 파일도 같은 규칙의 이름으로 이 폴더에 자동 저장돼, 폴더가 항상 최신 상태로 유지됩니다.
- 파일명 규칙에 안 맞으면 `imports.log`에 사유가 남고 건너뜁니다(다른 파일엔 영향 없음).
