# Handoff — 상태 저장

목표: 다음 세션이 **`.ai/CURRENT.md` + git 상태만 읽고** 곧바로 이어서 작업할 수 있게, 지금 상태를 압축 저장한다.

## 원칙
- **상태(state)를 저장하고, 대화(conversation)를 저장하지 않는다.** 로그·코드 덤프·긴 설명 금지.
- 코드나 git이 이미 말해주는 것은 적지 않는다. **비자명한 것만** 남긴다.
- 상대 날짜(오늘/어제/이번 주)는 **절대 날짜**로 바꾼다.

## 할 일
1. `.ai/CURRENT.md`를 아래 구조로 **간결하게 갱신**(덮어쓰기 아님, 최신화):
   - **Goal** — 무엇을 만드는가 (1~2줄).
   - **Status** — 지금 어디까지 왔는가 (한 줄).
   - **Stack/Arch** — 구조는 `DOCKER.md` / `.ai/ARCHITECTURE.md` 가리키기(중복 금지).
   - **Done** — 완료·검증된 사실 불릿 (핵심 수치 포함).
   - **Known issues / limitations** — 근사치·미완·주의점.
   - **Next action** — 다음 할 일 **딱 하나**, 구체적으로.
   - **Run / verify** — 기동·확인 명령어 그대로.
   - **Git state** — (git 저장소면) 브랜치 + 커밋 여부.
2. 앞으로 다시 논쟁하면 안 되는 **확정된 설계 결정**이 있으면 `.ai/DECISIONS.md`에 짧게 추가(맥락/결정/이유).
3. 요청받지 않았으면 **commit/push 하지 않는다.**

## 마무리
저장한 내용과 Next action을 **한 줄로** 확인해준다.
